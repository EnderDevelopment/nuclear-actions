# Electricity Redstone Expansion Mod

Electricity Redstone Expansion is a Minecraft mod for Java Edition 1.20.4, designed to enhance redstone functionality with electricity. This mod introduces a variety of blocks and items that allow players to create complex electrical systems, including energy cubes, extraction devices, cables, storage units, RAM chips, motherboards, and servers. The mod is built using the Fabric mod loader and is compatible with Minecraft version 1.20.4.

## Install

1. Download the mod file (`.jar`) from the releases section of the GitHub repository.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded correctly.

## Use

1. **Energy Cube**: Place four blocks to form an energy cube (reactor nuclear).
2. **Energy Extraction Devices**: Use these devices to connect to the energy cube and extract energy.
3. **Energy Cables**: Place cables to transport energy from the cube.
4. **Energy Storage Unit**: Store and distribute energy to multiple outputs.
5. **Distribution Cable**: Connect the storage output to an energy antenna to supply electricity.
6. **RAM Chips**: Place RAM chips with capacities of 16, 32, 64, and 128 on a motherboard.
7. **Motherboards**: Create four motherboard models, each with up to five chip slots. Energy is not activated without these chips.
8. **Servers**: Place a motherboard inside a server and connect it to the reactor nuclear. Use the server interface to add/remove RAM, add/remove motherboards, and turn the server on/off.
9. **Reactor Overload**: If a server with the required characteristics is left on for a long time, the reactor nuclear can overload and disappear.
